# 1. Agile Team Charter

## 1.1 Project Overview

**Project Name:** SafeStreet Community Security Solutions

SafeStreet is a community security platform designed to connect residents with security guards. The idea came from concerns about safety in South Africa, especially for people who leave home early in the morning or return late at night.

The purpose of the project is to provide a platform where residents can access security-related services while administrators manage information about residents and guards.

## 1.2 Project Objectives

- To provide a platform where residents can register.
- To allow security guards to register on the platform.
- To create dashboards for residents, guards, and administrators.
- To make the application simple and user-friendly.
- To provide a central platform for managing relevant information.
- To develop a practical solution to a community problem.
